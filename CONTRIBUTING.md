# Contributing to HAG Brokers

Thanks for helping improve HAG Brokers.

1. Open an issue explaining the bug or feature (omit private customer data).
2. Branch from `main`, keep changes narrowly scoped, and include tests.
3. Run the isolated SQLite test suite documented in README.
4. Submit a pull request describing behavior, security impact, migrations, and manual verification.
5. Never commit secrets or modify live database content. Do not push directly to `main`.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) and [Security Policy](SECURITY.md).
