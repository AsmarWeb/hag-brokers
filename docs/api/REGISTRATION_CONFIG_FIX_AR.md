# التحقق من تسجيل الهاتف وإعدادات المحتوى

تأكدت اختبارات الذاكرة من أن تسجيل الشركة دون company_name/phone/country_code يرجع أخطاء حقول ولا ينشئ سجلًا جزئيًا، وأن البريد الموجود يرجع خطأ email دون حساب ثانٍ. لا تغييرات جديدة في قواعد التسجيل أو الباقات أو migrations.

كان app-config في الإنتاج يرجع HTTP 200، version=0 والقيم الافتراضية أثناء الفحص. حفظ /admin/mobile-app يزيد version في نفس قاعدة الخادم. عند تعديل localhost لن تظهر القيم في تطبيق يستخدم hagbrokers.net. عند استخدام العربية، عدّل حقول العربية كذلك. يجب ألا يحل تشخيص المزامنة بنقل قواعد بيانات أو إنشاء مفاتيح في الهاتف.

هذه الحزمة تجمع إصلاح الحساب السابق مع إصلاح رسائل الحقول ومزامنة المحتوى. لا تغيّر الثقة بالتوكن أو صلاحيات إدارة المنصة. platform:mobile-check للقراءة فقط.
