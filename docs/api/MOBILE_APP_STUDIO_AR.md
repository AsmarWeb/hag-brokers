# استوديو محتوى تطبيق HAG Brokers

بعد نشر الكود وتشغيل migration الإضافية، افتح `/admin/mobile-app` بحساب إدارة موثّق. يوجد رابط في `/admin/settings`.

يمكن تعديل اسم الرأس داخل التطبيق، عنوان ووصف الترحيب والرئيسية بالعربية والإنجليزية، صور الترحيب والرئيسية، رسالة اختيارية، القطاعات المعروضة، وقسم الفرص البحرية. لا تؤثر الإعدادات على نشر الفرص وصلاحيات الشركات أو الأموال أو الخطط. تفضيلات اللغة والمظهر تخص كل جهاز في «حسابي».

الصور عامة ولا تقبل SVG أو الروابط الخارجية. JPEG/PNG/WebP فقط؛ 3MB كحد أقصى و4096px لكل بعد. صورة الترحيب المرفقة صورة تعبيرية مولدة وليست عرضًا تجاريًا حقيقيًا. لا تستخدم مستندات حساسة ضمن الصور. يحتفظ النظام بالصور السابقة من أجل تاريخ التغييرات؛ تنظيف الأصول غير المستخدمة مؤجل.

GET `/api/v1/app-config` للقراءة فقط، بدون Bearer. صور التخزين يجب أن تستخدم APP_URL وقرص public الصحيحين ورابط public/storage. كل حفظ يزيد version ويسجل هوية المدير والتاريخ والمحتوى. الحفظ القديم يرجع 409 بدل الكتابة فوق تغيير آخر. أعد فتح الصفحة عند حدوث تعارض.

الاسم أسفل أيقونة الهاتف، الأيقونة، شاشة النظام الأصلية قبل تحميل JavaScript، تخطيط الشاشات، الصلاحيات والكود تحتاج تحديث التطبيق. شاشة الترحيب الداخلية قابلة للإدارة. لا يمكن للإدارة إجبار لغة/مظهر المستخدم.

التطبيق يحوي صورة محلية افتراضية ويعمل إذا تعذر تحميل الإعدادات أو الصورة. أول استخدام يعرض الترحيب؛ بعدها التصفح مباشرة. يمكن إعادة عرض الترحيب من حسابي. تحديث المحتوى عند الفتح أو العودة بعد دقيقة أو السحب للتحديث.

## فحص على Hostinger بعد الدمج

```bash
cd /home/u498553347/domains/hagbrokers.net/public_html/src || exit 1
/opt/alt/php84/usr/bin/php artisan migrate --force &&
/opt/alt/php84/usr/bin/php artisan view:cache
```

لا تستخدم migrate:fresh أو db:wipe أو أي استعادة بيانات. الترحيل يضيف جدول إعدادات وجدول سجل فقط، ولا يعدل جداول الفرص أو المدفوعات.

تحقق من `/api/v1/app-config` بحالة 200 وظهور الصورة المرفوعة عبر public/storage. لا يستدعي المثبت migrations أو seeders أو tests تلقائيًا.
