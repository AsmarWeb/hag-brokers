# HAG Brokers — واجهة التطبيقات v1

هذا الإصدار يدعم المصادقة والتصفح وإدارة فرص الشركات عبر HTTPS وJSON. أضيفت عروض RFQ والتفاوض والتنبيهات الخاصة في v1.2؛ راجع TRADE_WORKFLOW_AR.md.

## المتاح الآن
- تسجيل فرد أو شركة، دخول، خروج، أجهزة، تأكيد بريد، استعادة كلمة مرور.
- تصفح الفرص وتفاصيلها بالـslug والبحث والتصنيف والدولة وترقيم الصفحات.
- التصنيفات والعملات والوحدات، والملف التجاري المنشور للشركة.
- قراءة مساحة الشركة والخطة الفعلية مع التحقق من البريد والعضوية والنشاط.

## العقد والتكامل
المواصفة: `docs/api/openapi-v1.json` (OpenAPI 3.1، قابلة للاستيراد في Postman وأدوات توليد العملاء).
الجذر الإنتاجي: `https://hagbrokers.net/api/v1`.
أرسل `Accept: application/json` و`Content-Type: application/json`.
المحمي يحتاج `Authorization: Bearer YOUR_TOKEN`.
اختر `?lang=ar` أو `?lang=en`؛ أو Accept-Language. القيم التجارية التي تكتبها الشركة لا تترجم تلقائيًا.
النجاح يعيد `data`، والقوائم تضيف `meta`. الأخطاء تستخدم `message` و`errors` عند فشل التحقق. الخروج والحذف يعيدان 204 دون body.
المبالغ سلاسل عشرية مع العملة الأصلية؛ لا تجمع عملات مختلفة. التواريخ UTC بصيغة ISO 8601.
اعرض النصوص التي يكتبها المستخدمون كنص آمن، لا HTML قابل للتنفيذ.

## التسجيل
الفرد: account_type=individual، name، email، password، password_confirmation، device_name.
الشركة: account_type=company ونفس الحقول مع company_name وphone وcountry_code من حرفين، وcity اختياري.
كلمة المرور الجديدة 12–128 حرفًا. تسجيل الشركة يستدعي خدمة إنشاء الشركة الحالية ويمنح الخطة المجانية. لا ينشئ تسجيل الفرد شركة أو صفة بائع موثق أو صلاحيات إدارية.
تحديد الحساب فرد/شركة هنا مبني على العضوية الحالية؛ ليس شهادة تحقق قانوني. الأفراد الحاليون المرتبطون بسجلات قديمة لا يُحوّلون تلقائيًا.

## أمان الأجهزة
الرمز صالح 30 يومًا وصلاحيته mobile:v1. لا يمكن لرمز بقدرة مختلفة أو جلسة متصفح فقط الدخول لهذه المسارات. مسؤولو المنصة لا يستخدمون هذه API.
كل تثبيت للتطبيق يختار device_name ثابتًا وفريدًا؛ إعادة الدخول بنفس الاسم تستبدل رمزه. يحتفظ النظام بحد أقصى 20 جهازًا متنقلًا. خزّن الرمز في Keychain/Keystore ولا تضعه في رابط أو سجل أو مستودع.
الخروج يبطل الجهاز الحالي. استعادة كلمة المرور تبطل جميع الرموز. رابط تأكيد البريد موقّع وصالح ساعة ويمكن فتحه بالمتصفح. رابط استعادة كلمة المرور يستخدم شاشة الويب الحالية؛ الربط العميق للتطبيق لاحقًا.
حد عام 120 طلبًا/دقيقة لكل IP؛ حدود مستقلة للدخول/التسجيل/الاستعادة 5، ولطلب رسالة استعادة/تأكيد 3. احترم 429 وRetry-After. لا تكرر طلب التسجيل تلقائيًا؛ إن حدث انقطاع بعد إنشاء الحساب، استخدم الدخول أو استعادة كلمة المرور.

## فصل الشركات وحماية البيانات
قراءة مساحة الشركة تحتاج تحقق البريد وعضوية مطابقة وعميل ومساحة نشطين. التعليق لا يحذف الرموز لكنه يمنع الوصول لمساحة الشركة؛ التصفح العام يظل عامًا.
الفرص تستخدم publicQuery نفسها في الموقع، فلا تُعرض الفرص المغلقة أو المنتهية أو المحجوبة أو التابعة لشركة معلقة. لا تُرسل الملاحظات أو عمولات الوساطة أو بيانات العميل الخاصة. الملف العام لا يعرض مستندات التسجيل.
لا تغيير لمسارات Stripe أو قاعدة البيانات أو إعدادات الإطلاق المجاني.

## المتبقي قبل التطبيق الكامل
1. إدارة الفرص أصبحت متاحة في v1.1؛ راجع COMPANY_OPPORTUNITIES_AR.md لعقد المراجعة والوسائط.
2. أصبحت عروض RFQ والمقارنة والتفاوض والملفات الخاصة وحالة القراءة والتنبيهات المدعومة متاحة في v1.2.
3. ربط Push Notifications وروابط التطبيق العميقة وإدارة تحديثات التطبيق.
4. تكامل الشركاء: بيانات اعتماد مستقلة وصلاحيات دقيقة وتوقيع Webhooks وIdempotency. لا تسلّم رمز المالك لشريك.
المراحل 3–4 أعلاه ما زالت مستقبلية؛ لا تستخدم مسارات الويب البديلة كعقد API ثابت.

## تصور التوسع الدولي
- اجعل الإمارات نقطة الانطلاق مع سوق تجاري دولي، بدل إطلاق كل البلدان دفعة واحدة.
- أفراد: تصفح وحفظ طلبات واهتمامات، ثم ترقية موثقة إلى شركة أو وسيط مستقل. لا تمنح شارة شركة موثقة للفرد.
- شركات: بائع/مشتري/مورد خدمات، مع توثيق مستندات منفصل حسب الدولة وصلاحيات فرق.
- المرحلة التالية للبيانات: ISO للدول، E.164 للهواتف، مناطق زمنية IANA، وحدات قياس وعناوين دولية، دون تغيير تواريخ العقود الحالية المرتبطة بتوقيت دبي.
- احتفظ بالمبلغ الأصلي والعملة؛ أسعار التحويل إن أُضيفت تكون للعرض مع مصدر ووقت واضحين، ولا تغيّر المستندات المالية المجمدة.
- مطابقة فرص وطلبات شراء حسب القطاع والبلد والقدرة على التوريد، مع شرح سبب الترشيح وموافقة الشركات على التنبيهات.
- أدلة موردين وصفحات قطاعات/دول ثنائية اللغة بمحتوى فعلي، ونظام بلاغات ومكافحة احتيال قبل التوسع.
- باقات الشركات مدفوعة لاحقًا؛ إعلانات مميزة موسومة بوضوح، ووساطة اختيارية باتفاق منفصل. لا تحصّل عمولة أو رسوم تلقائية في الإطلاق المجاني.
هذه خارطة منتج مقترحة؛ الميزات المستقبلية ليست مفعّلة ضمن الحزمة.
