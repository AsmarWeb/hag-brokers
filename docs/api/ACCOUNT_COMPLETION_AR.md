# إكمال الحساب والسياسات — HAG

هذه إضافة بعد الشحن PR46 / mobile PR3. لا dependencies أو ENV جديدة. ترحيل إضافي واحد يضيف طلبات حذف الحساب ومستندات السياسات وسجل نشرها. لا ينشر نصوصًا قانونية أو يمس السجلات الحالية.

## سلوك الحساب

من حسابي ← بيانات الحساب: تعديل الاسم والبريد. تغيير البريد يحتاج كلمة المرور الحالية، ويزيل التوثيق، ويلغي رموز API الأخرى مع إبقاء رمز الهاتف الحالي، ويطلب رسالة توثيق جديدة. إذا تعذر SMTP يبقى التعديل محفوظًا ويمكن إعادة الإرسال من أمان الحساب. لا ادعاء بوصول الرسالة بمجرد طلبها. البريد التجاري للشركة، الفواتير، الهويات المالية واللقطات السابقة تبقى مستقلة. جلسات الويب الحالية لا تُلغى بهذا المسار. التعديلات القديمة تُرفض بـ409 مع إعادة تحميل واضحة.

## طلب حذف الحساب

قائمة حسابي ← طلب حذف الحساب: كلمة مرور، موافقة ثم تأكيد. حالة pending أو reviewing وتاريخ الطلب. الطلب لا يحذف الحساب فورًا ولا يوقف الدخول ولا يمس الشركة أو الشحن والعروض والفواتير. إعادة الإرسال لا تنشئ صفًا آخر. لا نحتفظ بكلمة المرور في الطلب.

في الإدارة ← الحسابات والسياسات، أو /admin/account-center: قائمة طلبات وصفحات، وبدء المراجعة مع رقم إصدار وتسجيل معرف المراجع ووقته. لا زر «تم الحذف» وهمي. المعالجة الفعلية والتواصل مع صاحب الحساب مسؤولية فريق المنصة وخارج التنفيذ التلقائي لهذه الإضافة. لا يكتمل حذف البيانات بمجرد تغيير الحالة؛ لم نضف حذفًا جماعيًا أو حذف مالك شركة قد يضر بالسجلات. لا يدّعي هذا الإصدار اكتمال متطلبات أي متجر تطبيقات أو مدة قانونية للاحتفاظ أو موعدًا آليًا للمعالجة.

## الخصوصية والشروط

الزائر والمستخدم يستطيعان فتحهما من حسابي. API عام بلا Bearer ونصوص تعرض كنص عادي دون HTML. /legal/privacy و/legal/terms على الويب. الإدارة تكتب العنوان والنص في اللغتين وتختار النشر بعد المراجعة، مع رقم إصدار وسجل نصوص سابق. المسودات لا تظهر، وتضارب تعديل إداري يُرفض. لا نصوص قانونية مفترضة أو منشورة تلقائيًا. يجب مراجعة سياسة المنصة الفعلية وإدخالها ونشرها قبل الإطلاق. إذا لم تنشر الإدارة المستند يعرض الهاتف رسالة واضحة بأنه لم يُنشر.

## الاختبار

الاختبارات محلية SQLite :memory: معزولة، وليست MySQL الإنتاج أو هاتفًا حقيقيًا. يلزم اختبار هاتف فعلي مع بريد قابل للتوثيق بعد نشر الخلفية، وعدم نشر البيانات الشخصية أو كلمات المرور أو الرموز في المحادثة.
