# تنزيل Android وخريطة الفرص البحرية

مبني على backend main `09b22f1`. لا تعديل في مستودع الهاتف أو مفاتيح Expo/Firebase أو الخطة المجانية أو Stripe أو إعدادات الصيانة.

## الصفحات
- `/admin/public-experience`: إعدادات التنزيل والخريطة، بحساب إدارة موثق البريد، مع قائمة لإدارة مواقع الفرص البحرية.
- `/download?lang=ar` أو en: صفحة تعليمات تنزيل Android. ترجع 404 عند تعطيل التنزيل.
- تحرير فرصة بحرية لدى الشركة: زر إدارة الموقع العام، لمالك/مدير شركة نشطة موثقة فقط. يظهر نموذج مستقل لا يتداخل مع تعديل الفرصة.
- `GET /api/v1/maritime-map?lang=ar`: بيانات عامة قابلة للاستخدام في الهاتف مستقبلًا؛ لم نضف شاشة خريطة للهاتف بهذا التحديث.

## تنزيل التطبيق
التنزيل معطل افتراضيًا. أدخل الإصدار وتاريخ النشر ورابط HTTPS ثم فعّل التنزيل.
يقبل رابط صفحة بناء تطبيق HAG في Expo، أو ملف APK في `/downloads/` ضمن نطاق APP_URL/SEO_CANONICAL_URL فقط. لا يقبل روابط خارجية أخرى أو معاملات query أو بيانات دخول.
للتنزيل من الموقع: نزّل APK الناجح من EAS، ثم ارفعه عبر File Manager إلى `public_html/src/public/downloads/hag-brokers-1.0.0.apk`، وأدخل `https://hagbrokers.net/downloads/hag-brokers-1.0.0.apk` في الإدارة. اختبر تنزيل الملف قبل تفعيل الزر. لا تضف APK إلى Git ولا ترفع مفاتيح أو Service Account. استخدم هوية الحزمة ومفتاح التوقيع نفسهما لتحديث التطبيق المثبت. رابط Expo يفتح صفحة التثبيت ولا يستضيف APK على نطاق الموقع. لا تنتج هذه الحزمة APK جديدًا.

## الخريطة
أزيلت سفن HAG DEMO والسرعات والوجهات والمسارات التجريبية وأعداد 24/138 من قسم الخريطة.
تعرض حتى 300 من أحدث الفرص البحرية العامة المتاحة للبيع/التأجير مع فلاتر وصور وروابط وقائمة يمكن استخدامها دون تحميل الخرائط. الموانئ من جدول ports، نشطة وبإحداثيات صحيحة؛ لا بيانات افتراضية إذا كانت القاعدة فارغة.
السفن الداخلية في vessels لا تنشر تلقائيًا؛ المصدر opportunity_vessels المرتبط بفرصة منشورة. لا مصدر AIS ولا تتبع مباشر ولا GPS أو geocoding.
يختار المالك/المدير أو الإدارة الموقع ويؤكد التخويل بنشره للعامة. التقريب لمنزلتين عشريتين يقلل الدقة ولا يضمن إخفاء الموقع أو الهوية. لا إحداثيات افتراضية للفرص. التعطيل يمسح الإحداثيات من السجل الحالي؛ تبقى سجلات المراجعة الداخلية.
كل طلب عام يستبعد الخاص والمخفي والمغلق والمنتهي وشركات/عملاء غير نشطين. صفحة مفتوحة سابقًا قد تحتفظ بالعلامات إلى إعادة التحميل؛ صفحة الفرصة تعيد فحص الإتاحة دائمًا.
لا تعديل لأسعار الفرصة أو سجلها أو حصتها أو الفواتير. الحفظ برقم إصدار وسجل مراجعة داخل معاملة. النموذج القديم يعيد 409؛ أعد تحميل الصفحة قبل الحفظ.
الخريطة تستخدم Leaflet وOpenStreetMap كما في النسخة السابقة؛ تحميل الخرائط يتصل بمزودي الموارد الخارجية. راجع الإفصاح في سياسة الخصوصية. لا تحليلات أو تتبع أشخاص جديدة.

## النشر
migration واحدة تنشئ public_experience_settings وopportunity_map_locations وpublic_experience_audits. لا ترحيل بيانات تلقائيًا ولا حذف بيانات.
انشر الملفات ثم migrate --force قبل فتح الرئيسية، ثم route:clear وview:cache. خذ نسخة احتياطية حديثة قبل نشر الإنتاج. لا تشغّل PHPUnit على قاعدة الإنتاج. لا يلزم npm build لهذا التحديث لأن التنسيق الجديد ضمن قوالب محصورة، ولا تعديل CSS/Vite.
الاختبارات المعزولة: PublicExperienceTest مع PublicSeoTest وCompanyMarketplaceTest وPremiumMarketplaceTest وMobileAppSettingsTest وCompanyOpportunityApiTest.
لم تُعدّل قاعدة الإنتاج أو يُنشر أي ملف إلى Hostinger تلقائيًا.
